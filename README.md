# GestioFlex — Scarica il programma

GestioFlex è un gestionale per piccole attività (negozi, parrucchieri, ristoranti, idraulici,
studi professionali…) che funziona **sul tuo computer, senza internet e senza abbonamenti**.

## Scarica

| Sistema | File |
|---|---|
| **Windows 10 / 11** | [**Scarica GestioFlex per Windows**](https://github.com/carlot43/gestioflex-download/releases/latest/download/GestioFlex-Setup.exe) |
| macOS (Apple Silicon) | [Scarica GestioFlex per Mac](https://github.com/carlot43/gestioflex-download/releases/latest/download/GestioFlex.dmg) |

## Installazione su Windows (2 minuti)

1. Apri il file scaricato `GestioFlex-Setup.exe`.
2. Se compare la finestra blu **"PC protetto da Windows"**: clicca **Ulteriori informazioni** e poi **Esegui comunque**. È normale per i programmi di piccoli produttori non ancora "firmati" da Microsoft.
3. Avanti → Avanti → Installa. Al termine trovi GestioFlex sul desktop.
4. Al primo avvio scegli il tuo tipo di attività, inserisci il nome dell'attività e crea il tuo utente.
5. **Conserva il codice di recupero** che compare alla fine: serve se dimentichi la password.

## Installazione su Mac

Apri il file `.dmg`, trascina GestioFlex nella cartella Applicazioni. Al primo avvio: tasto destro sull'icona → **Apri** → Apri.

## Versione dimostrativa e licenza

Il programma parte in versione dimostrativa: **tutte le funzioni sono disponibili**, i documenti PDF riportano la dicitura "versione dimostrativa". All'acquisto ricevi un codice licenza: incollalo in **Impostazioni → Licenza** e la dicitura sparisce. Non serve la connessione a internet.

## I tuoi dati

Restano solo sul tuo computer. Il programma fa un backup automatico ogni giorno
(Impostazioni → Backup): ti consigliamo di indicare come cartella dei backup una chiavetta USB
o una cartella sincronizzata (Google Drive, Dropbox, OneDrive).
